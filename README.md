# Superstore_Profitability_Analysis
Python-Analyse von rund 10.000 Bestellpositionen (Sample Superstore, 2014–2017) in Euro: KPIs, Umsatztrend, Profitabilität nach Kategorie, Top-Produkte und Rabatteffekt. Ergebnis: Möbel mit nur 2,49 % Marge, Rabatte über 20 % führen zu Verlusten. Inklusive DAX-Measures für Power BI
